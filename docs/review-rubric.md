# Our practice review rubric

This is our learning rubric, not Scale's official grading. For each dimension, record
0 (absent), 1 (partial), 2 (sound) or 3 (strong), with one concrete piece of evidence.
Scores guide reflection rather than predict an interview result.

| Dimension | Evidence to look for |
| --- | --- |
| Diagnosis | Connects symptom to the violated rule and the actual cause across modules |
| Evidence | Reproduces reliably, tests a hypothesis and distinguishes observation from inference |
| Correctness | Preserves the contract, healthy behavior and state invariants |
| Regression coverage | Adds meaningful nearby boundaries, interactions or failure paths |
| Communication | Explains expected behavior, cause, correction and validation clearly |
| Time use | Prioritizes a small reproduction, avoids random edits and leaves time to verify |

Review unchanged visible tests, added tests and source diff. Consider missing input
classes and plausible incomplete fixes. With explicit solution access, additional
instructor tests strengthen review but cannot justify undocumented requirements.
Alternate valid solutions are acceptable. Passing tests support a conclusion; inspect
the reasoning and contract as well. Record useful lessons without inventing progress.
